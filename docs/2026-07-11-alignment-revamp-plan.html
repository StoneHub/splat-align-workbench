Known boundaries

  • Merged export intentionally rejects non-vertex PLY element payloads until their preservation semantics are implemented.
  • The current renderer/export lane supports binary little-endian, float32 vertex splat layouts; unsupported layouts now fail explicitly instead of being silently misread.
  • Higher-order spherical-harmonic coefficients are not rotated during export yet. That is an appearance-fidelity gate, not a cosmetic backlog item.
  • No server upload path is introduced. Files remain local in browser memory.
